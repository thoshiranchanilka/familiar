# Claude Puppet v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut idle power to near zero, add a right-click menu, a settings window with three mascots, and a free sharing setup.

**Architecture:** Same Tauri 2 app on branch `feat/mascot`. Timers become deadline-driven and animation becomes level-aware. A generic pixel renderer draws any mascot definition. A second "settings" window talks to the Rust core through commands. Settings live in the Rust `settings.rs` file.

**Tech Stack:** Tauri 2 (+ `tauri-plugin-single-instance`), Rust (sysinfo, objc2-app-kit, objc2-foundation), TypeScript + Vite (multi-page) + Vitest, GitHub Actions (`tauri-apps/tauri-action`).

**Spec:** `docs/superpowers/specs/2026-11-17-mascot-v2-design.md` (builds on `2026-11-17-claude-mascot-design.md`)

## Global Constraints

- macOS on Apple Silicon only.
- Idle targets over 30 s, app plus web view helpers combined: average CPU ≤ **0.3%**, energy score ≤ **0.5** (`top -stats power`). Missed targets are reported, never silently loosened.
- Animation levels: `full` (8 fps always), `gentle` (default: 8 fps in working/thinking/done/greeting/error; idle still + blink about every 4 s; sleeping 2 fps), `still` (redraw on mood change only). Low Power Mode forces `still`.
- Hover polling: 4×/s (250 ms), and none while `hidden`.
- Claude Desktop watcher: no whole-system process scan while Claude Desktop isn't running; checks at most once per 2 s while it isn't running; Claude-only CPU sampling 1×/s while it runs.
- Mascots: `ember` (default), `mochi`, `bolt`. Unknown ids fall back to `ember`. The app icon stays Ember.
- Settings save immediately; v1 settings files keep loading (new fields default).
- Size range 64–192 px.
- v1 constraints still hold: the localhost-only token-checked server, no conversation content, safe settings.json edits, click-through overlay.
- Never push, publish, or create a GitHub repo.

## Review Focus

- A v1 `~/.claude-mascot/settings.json` with no `mascot` or `animation` field: loads with defaults, nothing lost.
- Ember hidden while the menu-bar icon is behind the notch: reopening the app shows Ember and opens Settings.
- Settings opened twice (menu twice, or reopen app): one window, focused, not two.
- Low Power Mode toggled while running: Ember switches to still frames within about a minute and back after.
- Claude Desktop quit while a reply was "working": activity stops, and sampling stops within 2 s.

## File Structure

- `scripts/power-check.sh`: measures a running build and enforces the targets.
- `src/mood/reducer.ts`: adds `nextDeadline`.
- `src/ui/mascot/defs/{types,ember,mochi,bolt,index}.ts`: mascot definitions + registry.
- `src/ui/mascot/render.ts`: `mascotPixels(def, mood, f)` (replaces `ember.ts`).
- `src/ui/mascot/animation.ts`: frame policy per level and mood.
- `src/ui/mascot/mascot.ts`: canvas painter; redraws on change only.
- `src/ui/overlay.ts`: deadline timer, right-click, settings wiring.
- `settings.html`, `src/settings/settings.ts`, `src/settings/settings.css`: the settings window.
- `src-tauri/src/settings.rs`: `mascot` and `animation` fields.
- `src-tauri/src/power.rs`: Low Power Mode detection.
- `src-tauri/src/desktop_monitor.rs`: cheap watcher.
- `src-tauri/src/lib.rs`: single instance, context menu, settings window, commands.
- `src-tauri/tauri.conf.json`: ad-hoc signing.
- `.github/workflows/release.yml`, `README.md`.

## Shared Interfaces

```ts
// src/ui/mascot/defs/types.ts
export type Animation = "full" | "gentle" | "still";
export interface MascotDef {
  id: "ember" | "mochi" | "bolt"; name: string; kind: string; blurb: string;
  pal: Record<string, string>;   // map letter -> color
  map: string[];                 // 16 rows of 16 chars, "." = transparent
  eye: string; glow: boolean;    // glow: eyes and mouth drawn in `eye` color, no white highlight
  eyes: { l: number; r: number; y: number }; mouth: { x: number; y: number };
  blinkLetter?: string;          // map letter that blinks while working (Bolt's antenna "a")
}
// Settings shape shared by Rust (camelCase JSON) and TS
export interface Settings { corner: "br"|"bl"|"tr"|"tl"; size: number; autoHide: boolean; hidden: boolean;
  mascot: string; animation: Animation }
```

### Task 1: Power check (the gate)

**Files:**
- Create: `scripts/power-check.sh`

**Interfaces:**
- Produces: `scripts/power-check.sh [app-path]`. It launches the app (default: the release bundle), waits 15 s, samples `top -l 11 -s 3 -stats pid,cpu,power` for the app PID and its `WebKit.WebContent`/`WebKit.GPU` children (matched by parent or start time after launch), and prints `cpu_avg=… energy_avg=…`. It exits 1 if `cpu_avg > 0.3` or `energy_avg > 0.5`. It never kills a copy it didn't launch, and quits the copy it launched by PID.
