// install

Two minutes, four steps

Familiar is free. It isn't signed with a paid Apple developer account, so macOS asks you to approve it once.

  1. Download

    Get the latest .dmg from the Releases page. Open it and drag Familiar into Applications.

  2. Allow it once

    Open Familiar. macOS will block it the first time. Go to System Settings → Privacy & Security, scroll down to the message about Familiar, then click Open Anyway and confirm.

    Prefer Terminal? This does the same:

    xattr -dr com.apple.quarantine "/Applications/Familiar.app"

  3. Connect Claude Code

    Your mascot says "Click me to connect Claude Code." Click it, or right-click it and choose Connect Claude Code.

  4. Start a session

    Run claude in any terminal and your mascot pops up. Type /exit and it waves goodbye.

You'll need

  • A Mac with Apple Silicon (M1 or newer)
  • macOS 12 Monterey or later
  • Claude Code installed

On a work Mac managed by IT, policy may block apps that aren't notarized. Ask your IT team if Open Anyway doesn't appear.

Using Familiar

When it shows up Controls Settings Privacy Power Uninstall

When it shows up

  • It appears when a Claude Code session starts, in any terminal. It also works in Claude Desktop's Code tab if your version runs Claude Code hooks there.
  • It hides when you exit, or after 5 quiet minutes if a terminal was closed without exiting.
  • During long tasks it waits up to 30 minutes, so it never vanishes mid-build.
  • Claude Desktop chat isn't supported, because the app doesn't share what it's doing.

Controls

Hover
Shows the model, your limits and context used.
Drag
Move it anywhere on screen. It remembers the spot.
Right-click
Settings, Hide, Connect or Disconnect, and Quit.
Reopen the app
Open Familiar from Applications or Spotlight to bring the mascot back and open Settings.

Settings

Mascot
Any of the nine.
Size & position
Pick a corner, or open Advanced to place it exactly with sliders.
Animation
Gentle (default) animates only while Claude is busy. Full always animates. Still never does.
Open at login
On by default, so it's always ready.

Privacy

  • Everything stays on your Mac. The app only listens on 127.0.0.1, and every request needs a random token.
  • The hook sends only the event name, session id and model. It never sends prompts, replies, files or tool output.
  • The status line passes Claude Code's status data to the app locally. Familiar uses only the model, context and rate limits, and stores nothing.

Uninstall

  1. Right-click the mascot and choose Disconnect Claude Code. This restores your settings.
  2. In Settings, switch off Open at login, then quit.
  3. Delete Familiar from Applications, and delete the ~/.claude-mascot folder.

Questions

Claude Code prints "hook failed … ECONNREFUSED"

Those messages come from an old version's hooks. Open Familiar once and it switches to the new quiet hook automatically. The messages stop, even while Familiar is closed.

The mascot doesn't appear

Make sure it's connected: right-click it, and the menu says Disconnect when it is. Then start a new Claude Code session. If you hid it, open Familiar again from Applications.

Does it work with Claude Desktop?

It works with the Code tab, if your Claude Desktop version runs Claude Code hooks there. Regular Desktop chat isn't supported.

Why does macOS warn me about the app?

Apple's notarization needs a paid developer account, and Familiar is a free hobby project. All the source is on GitHub, and apps you build yourself open without the warning.

Is there a Windows version?

Not yet. Familiar is Mac-only for now.

Is this made by Anthropic?

No. Familiar is an unofficial fan project, and isn't affiliated with or endorsed by Anthropic.
