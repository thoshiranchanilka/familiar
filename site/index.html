        How it works
        
It shows up when you do

        
No windows to manage. Familiar waits quietly in the background and appears only while a Claude Code session is running.

        

          

            
            
Pops in

            
Start Claude Code in any terminal and your mascot hops into the corner with a little hello.

          

          

            
            
Reacts

            
It types while Claude works, sweats when it's thinking longer, cheers when it's done, and winces at errors.

          

          

            
            
Usage at a glance

            
Hover over it to see the model, your 5-hour and weekly limits with reset times, and context used.

          

          

            
            
Barely sips power

            
Hidden between sessions and redrawn only when the picture changes. About what a menu-bar clock uses.

        Install
        
Up and running in two minutes

        
Familiar is free and open source. It isn't signed with a paid Apple developer account, so macOS asks you to approve it once.

        
    
          
  1. 
            
    Download
    
            
    Get the latest .dmg from the Releases page, open it, and drag Familiar into Applications.
    
          
    2. 
          
  2. 
            
    Allow it once
    
            
    Open Familiar. macOS will block it the first time. Go to System Settings → Privacy & Security, scroll down to the message about Familiar, click Open Anyway and confirm.
    
            
    Comfortable with Terminal? This does the same:
    
            
    xattr -dr com.apple.quarantine "/Applications/Familiar.app"
    
            
    On a work Mac managed by IT, policy may block apps that aren't notarized. Ask your IT team if Open Anyway doesn't appear.
    
          
    3. 
          
  3. 
            
    Connect Claude Code
    
            
    Your mascot says "Click me to connect Claude Code." Click it (or right-click → Connect Claude Code). It adds a few entries to ~/.claude/settings.json and saves a backup first.
    
          
    4. 
          
  4. 
            
    Start a session
    
            
    Run claude in any terminal. Your mascot pops up. Type /exit and it waves goodbye.
    
          
    5. 
        

      


      

        Docs
        
Using Familiar

        

          

            
When it shows up

            
    
              
  • It appears when a Claude Code session starts, in any terminal, and in Claude Desktop's Code tab if your version runs Claude Code hooks there.
    • 
              
  • It hides when you exit, or after 5 quiet minutes if a terminal was closed without exiting.
    • 
              
  • During long tasks it waits up to 30 minutes, so it never vanishes mid-build.
    • 
              
  • Claude Desktop chat isn't supported: the app doesn't share what it's doing.
    • 
            

          

          

            
Controls

            
    
              
  • Hover the mascot for model, limits and context used.
    • 
              
  • Right-click it for Settings, Hide, Connect/Disconnect and Quit.
    • 
              
  • Drag it anywhere on screen. It remembers the spot.
    • 
              
  • Want it now? Open Familiar again from Applications or Spotlight: the mascot appears and Settings opens.
    • 
            

          

          

            
Settings

            
    
              
  • Mascot: any of the nine.
    • 
              
  • Size and corner of the screen, plus Advanced sliders to place it exactly.
    • 
              
  • Animation: Full, Gentle (default: animates only while Claude is busy) or Still.
    • 
              
  • Open at login: on by default, so it's always ready.
    • 
            

          

          

            
Privacy

            
    
              
  • Everything stays on your Mac. The app listens only on 127.0.0.1 and requires a random token.
    • 
              
  • The hook sends only the event name, session id and model. Never prompts, replies, files or tool output.
    • 
              
  • The status line passes Claude Code's status data locally; Familiar uses only model, context and rate limits, and stores nothing.
    •

Uninstall

            
    
              
  1. Right-click the mascot → Disconnect Claude Code (restores your settings).
    2. 
              
  2. In Settings, switch off Open at login, then quit.
    3. 
              
  3. Delete Familiar from Applications, and the ~/.claude-mascot folder.
    4. 
            

          

        

      


      

        FAQ
        
Questions

        

          

            Claude Code prints "hook failed … ECONNREFUSED"
            
That's an old version's hooks. Open Familiar once: it switches to the new quiet hook automatically, and the messages stop, even when Familiar is closed.

          

          

            The mascot doesn't appear
            
Check that it's connected (right-click → the menu says Disconnect when it is), then start a new Claude Code session. If you hid it, open Familiar again from Applications.

          

          

            Does it work with Claude Desktop?
            
With the Code tab, if your Claude Desktop version runs Claude Code hooks there. Regular Desktop chat isn't supported.

          

          

            Why does macOS say it can't check the app for malware?
            
Apple's notarization needs a paid developer account, and Familiar is a free hobby project. The source is all on GitHub, and apps you build yourself open without the warning.

          

          

            Can I build it myself?
            
Yes: install Node 20+, Rust and the Xcode command-line tools, then npm install and npm run tauri build. See the README on GitHub.

          

          

            Is this made by Anthropic?
            
No. Familiar is an unofficial fan project and isn't affiliated with or endorsed by Anthropic.
