01How a session goes

Familiar stays out of sight until you start Claude Code. Then it keeps you company.

  1. Pops inStart claude in any terminal and it hops into the corner.
  2. Works alongTaps away on its little keyboard while Claude edits and runs things.
  3. Thinks longerAfter 15 seconds it starts to sweat a bit, so you know it's a big one.
  4. CelebratesHops and sparkles when Claude finishes. Winces if something fails.
  5. Heads offType /exit and it waves goodbye. Nothing runs while it's gone.

04Docs

Familiar Help
  • It appears when a Claude Code session starts, in any terminal. It also works in Claude Desktop's Code tab if your version runs Claude Code hooks there.
  • It hides when you exit, or after 5 quiet minutes if a terminal was closed without exiting.
  • During long tasks it waits up to 30 minutes, so it never vanishes mid-build.
  • Claude Desktop chat isn't supported: the app doesn't share what it's doing.
  • Hover the mascot for the model, limits and context used.
  • Drag it anywhere on screen. It remembers the spot.
  • Right-click it for Settings, Hide, Connect or Disconnect, and Quit.
  • Want it now? Open Familiar again from Applications or Spotlight: the mascot appears and Settings opens.
  • Mascot: any of the nine.
  • Size and corner, plus Advanced sliders to place it exactly.
  • Animation: Full, Gentle (the default, which animates only while Claude is busy) or Still.
  • Open at login: on by default, so it's always ready.
  • Everything stays on your Mac. The app listens only on 127.0.0.1 and requires a random token.
  • The hook sends only the event name, session id and model. Never prompts, replies, files or tool output.
  • The status line passes Claude Code's status data to the app locally. Familiar uses only the model, context and rate limits, and stores nothing.

05Help

Claude Code prints "hook failed … ECONNREFUSED"

Those messages come from an old version's hooks. Open Familiar once and it switches to the new quiet hook automatically. The messages stop, even when Familiar is closed.

The mascot doesn't appear

Check that it's connected: right-click it, and the menu says Disconnect when it is. Then start a new Claude Code session. If you hid it, open Familiar again from Applications.

Does it work with Claude Desktop?

Yes, with the Code tab, if your Claude Desktop version runs Claude Code hooks there. Regular Desktop chat isn't supported.

Why does macOS warn me about the app?

Apple's notarization needs a paid developer account, and Familiar is a free hobby project. All the source is on GitHub, and apps you build yourself open without the warning.

Can I build it myself?

Yes. Install Node 20+, Rust and the Xcode command-line tools, then run npm install and npm run tauri build. The README on GitHub has the details.

Is this made by Anthropic?

No. Familiar is an unofficial fan project and isn't affiliated with or endorsed by Anthropic.
